# Client Code Generation from OpenAPI

**Target Cell:** `fe-openapi` (`web/openapi`)
**Dependencies:** Completion of `01_openapi_specification__api-openapi.md`
**Status:** Not Started

## Overview

Generate a TypeScript client library from the OpenAPI specification using `openapi-typescript-codegen`. This provides type-safe API access for the web UI with full TypeScript support.

## Background

The `fe-openapi` cell (`web/openapi`) generates the `@colony2/openapi-client` package used by all web applications. The package.json already has a `generate` script configured.

## Goals

1. Run code generation to produce TypeScript client
2. Verify generated types and services
3. Build and publish the client package
4. Make available to `web-app` and other consumers
5. Document generated API for UI developers

## Current Configuration

**File:** `/src/web/openapi/package.json`

```json
{
  "name": "@colony2/openapi-client",
  "scripts": {
    "generate": "openapi --input ../../api/openapi/colony2-api.yaml --output ./src/generated --client fetch",
    "build": "tsup src/index.ts --format cjs,esm --clean && tsc --emitDeclarationOnly",

}
```

**File:** `/src/web/openapi/src/generated/services/RecipesService.ts`

```typescript
/* generated by openapi-typescript-codegen */

import type { CreateRecipeRequest } from '../models/CreateRecipeRequest';
import type { PublishRecipeRequest } from '../models/PublishRecipeRequest';
import type { RecipeHistoryResponse } from '../models/RecipeHistoryResponse';
import type { RecipeListResponse } from '../models/RecipeListResponse';
import type { RecipeVersion } from '../models/RecipeVersion';
import type { RecipeWithContent } from '../models/RecipeWithContent';
import type { UpdateRecipeRequest } from '../models/UpdateRecipeRequest';
import type { PublishedRecipe } from '../models/PublishedRecipe';

import type { CancelablePromise } from '../core/CancelablePromise';
import { OpenAPI } from '../core/OpenAPI';
import { request as __request } from '../core/request';

export class RecipesService {
    /**
     * List recipes
     * List all recipes in a project with optional status filtering
     * @param projectId Project ID
     * @param status Filter by publish status
     * @returns RecipeListResponse List of recipes
     * @throws ApiError
     */
    public static listRecipes(
        projectId: string,
        status?: 'all' | 'published' | 'unpublished',
    ): CancelablePromise<RecipeListResponse> {
        return __request(OpenAPI, {
            method: 'GET',
            url: '/projects/{projectId}/recipes',
            path: {
                'projectId': projectId,
            },
            query: {
                'status': status,
            },
        });
    }

    /**
     * Create recipe
     * Create a new recipe (optionally auto-publish)
     * @param projectId Project ID
     * @param requestBody
     * @returns RecipeVersion Recipe created
     * @throws ApiError
     */
    public static createRecipe(
        projectId: string,
        requestBody: CreateRecipeRequest,
    ): CancelablePromise<RecipeVersion> {
        return __request(OpenAPI, {
            method: 'POST',
            url: '/projects/{projectId}/recipes',
            path: {
                'projectId': projectId,
            },
            body: requestBody,
            mediaType: 'application/json',
        });
    }

    /**
     * Get recipe
     * Get a recipe with content (published version or specific ref)
     * @param projectId Project ID
     * @param recipeName Recipe name (can include slashes, URL-encoded)
     * @param ref Git reference (commit, tag, branch). Empty = published version
     * @returns RecipeWithContent Recipe details
     * @throws ApiError
     */
    public static getRecipe(
        projectId: string,
        recipeName: string,
        ref?: string,
    ): CancelablePromise<RecipeWithContent> {
        return __request(OpenAPI, {
            method: 'GET',
            url: '/projects/{projectId}/recipes/{recipeName}',
            path: {
                'projectId': projectId,
                'recipeName': recipeName,
            },
            query: {
                'ref': ref,
            },
        });
    }

    // ... other methods (update, delete, publish, unpublish, getHistory)
}
```

Type-safe TypeScript client for the Colony2 API, generated from the OpenAPI specification.

### Import Services and Types

\`\`\`typescript
import {
  RecipesService,
  type RecipeInfo,
  type RecipeWithContent,
  type CreateRecipeRequest,
} from '@colony2/openapi-client';
\`\`\`

### Configure Base URL

\`\`\`typescript
import { OpenAPI } from '@colony2/openapi-client';

// Set base URL for API calls
OpenAPI.BASE = 'https://api.example.com/api/v1';

// Set auth token if needed
OpenAPI.TOKEN = 'your-auth-token';

### Recipe Service Examples

\`\`\`typescript
// List recipes
const response = await RecipesService.listRecipes('proj_123', 'published');
response.recipes.forEach(recipe => {
  console.log(recipe.name, recipe.publishedAt);
});

// Create recipe
const version = await RecipesService.createRecipe('proj_123', {
  name: 'workflows/ci/build',
  content: 'version: "1.0"\\n...',
  autoPublish: true,
});

// Get recipe
const recipe = await RecipesService.getRecipe(
  'proj_123',
  'workflows/ci/build',
  'v1.0.0' // optional version ref
);

// Update recipe
const updated = await RecipesService.updateRecipe(
  'proj_123',
  'workflows/ci/build',
  {
    content: 'version: "1.1"\\n...',
    message: 'Update build config',
    autoPublish: false,
  }
);

// Publish recipe
const published = await RecipesService.publishRecipe(
  'proj_123',
  'workflows/ci/build',

    publishedBy: 'user@example.com',
  }
);

// Get history
const history = await RecipesService.getRecipeHistory(
  'proj_123',

### Type Safety

All API calls are fully typed:
- Request parameters are validated at compile time
- Response types are inferred automatically
- Nullable fields are properly typed as \`T | null\`
- Optional fields use TypeScript's \`?\` operator

## Generated Code

Do not edit files in \`src/generated/\` - they are regenerated from the OpenAPI spec.

Generated structure:
- \`models/\` - TypeScript interfaces for request/response types
- \`services/\` - API service classes with methods for each endpoint
- \`core/\` - HTTP client infrastructure

## Troubleshooting

### Issue: Types not generated

**Solution:**
- Verify OpenAPI spec is valid
- Check input path in package.json generate script
- Ensure `openapi-typescript-codegen` is installed

### Issue: Build fails

**Solution:**
- Run `npm install` to ensure dependencies are installed
- Check for TypeScript errors: `npx tsc --noEmit`
- Verify all imports resolve correctly

### Issue: Consumers can't import

**Solution:**
- Ensure package is built: `npm run build`
- Check package.json exports configuration
- Verify consuming package has dependency: `"@colony2/openapi-client": "workspace:*"`
